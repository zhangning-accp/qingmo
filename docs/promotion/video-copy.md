# 视频发布文案

标题：Markdown 表格难改？点格修改、编辑公式，再导出 Word｜轻墨实机演示

简介：

整理教案、试题或项目方案时，Markdown 表格怎么改，数学公式怎么编辑，最后怎么转成 Word？这段视频用轻墨 0.4.8 演示了一遍：改一个单元格，加一行讲评，把小数改成分式，导出 DOCX。结尾是在 WPS 中继续修改导出文档的实际页面。

轻墨支持 Windows 10/11 64 位，需要 WebView2。源码和 EXE 都已公开；常见公式可以转成可编辑的 Office 公式，复杂公式会给提示。
